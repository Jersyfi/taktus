# Contributing

**Not yet.**

This repository is public so the work is visible, but it is under a reservation of all rights
(`LICENSE`) and no licence has been chosen (`NOTICE`, `docs/adr/ADR-0012-licensing.md`).

Accepting an outside pull request now would mean taking in code that belongs to its author under
unclear terms, and any later licence decision would need that author's agreement. So the order is:
licence first, contributor agreement second, contributions third.

**What is welcome in the meantime:** issues. Questions about the architecture, holes in the
reasoning, a contract that would not work for a tool you know — all of that is useful and costs
nothing legally. Open an issue.

**When contributions open** (planned for `1.0.0`), the rules will be: Conventional Commits,
trunk-based development, one pull request per change, and architectural changes arriving as an ADR
rather than as a pull request without context. The working doctrine is in `CLAUDE.md` and applies to
human and machine contributors alike.
