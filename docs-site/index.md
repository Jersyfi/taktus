# Taktus

Taktus runs an organisation's recurring work as processes. For each step it chooses a method,
carries the step out or has it carried out, and records what happened. People keep the decisions.

This documentation has three guides:

- **Using Taktus**: asking for work, following it, deciding, and reading the figures. No technical
  knowledge is assumed.
- **Administering Taktus**: installing, configuring, operating and restoring an installation.
- **Developing on Taktus**: writing processes, and building connectors, workers and model
  adapters.

Every page is generated from the Taktus repository. Its last lines name the commit it was taken
from.
