# Open decision requests

One file per request, `DEC-NNNN-<slug>.md`, in the shape of [../TEMPLATE.md](../TEMPLATE.md).
Every file here has a matching GitHub issue labelled `decision-request`. A file leaves this
directory in the same commit that writes its record into [../](../README.md).

While a file with `**Category:** BLOCKING` is here, the pull request that raised it stays a draft.
