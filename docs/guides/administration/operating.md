Operating an instance means three things. Showing that it survives a restart. Watching that the
machine it runs on does not run out of room. Showing that every integration can be removed
without breaking a process. An **integration** is anything outside Taktus that Taktus uses: a
worker that carries out work, a connector to another system, a language model.

This page shows each of the three: the check of a restart, the report on the machine, and the
removal test.
