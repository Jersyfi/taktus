# Status of `0.5.0` — value and dependency measurable

Part of `docs/status.md`: how far `0.5.0` has got, checked against the code and the tests.
What the milestone must reach is in `docs/roadmap.md`. Kept current by every pull request that
changes its state.

**A person takes over a running step** (ADR-0128, #404). Built in the engine, the runner, the
queue (migration `0064`) and the HTTP surface: a take-over is asked on the run's job by the
first asker only, the worker stops at its next boundary, its state becomes an artifact, and the
person holds the job under a claim of their own for eight hours. The hand-back is a `human`
step with provenance, written under that claim; a lapsed claim gives the step back to its
worker at the checkpoint. The web app's run page offers it on a running worker step, shows the
state and the lease's end, reads the result back before it is handed back, and says when a
take-over lapsed or was refused; the run level says where each served take-over stands. The
owner's conversation reads `take over <run> <step>`, `show takeover <takeover>` and `hand back
<takeover>: <result>`, and acts only on a confirmed reading. Still open: the MCP surface waits
for #406, and the automated takeover test of UC-6.3 does not yet exercise it.

**A step sees only the data of its case** (ADR-0130, UC-7.7, #432). Built in the run, at
registration, in the connector contract and in governance (migration `0065`): a step's `scope`
names its subject from the run's inputs and rides on every connector call; a scoped capability
refuses another subject's data with `out_of_scope`, recorded as `frame.refused`; an `analytic`
step reaches its one source through reads only, a source the tenant declares free of personal
fields with `taktusctl sources`; a step that reads personal data outside a case waits for a
person at every level; the provenance record names the scope. Defaults by NTC-0224. Still open:
the conformance suite does not yet check a scoped capability, and no connector here serves one.

**Taktus watches its platform** (ADR-0031). The *Observe* stage is built: free CPU, memory and
storage, growth per run extrapolated to a date, `taktusctl capacity` and a report by the
scheduler, admission against free capacity, every job's memory limit enforced or the job
refused. *Propose* (`0.5.0`) and *Manage* (`0.7.0`) are specified in
`docs/architecture/platform.md`.

**UC-4.19 requires the take-over of a running step** (NTC-0223, DEC-0195 W3). A person takes a
worker step out of a running run, receives its state, and hands the result back as a `human`
step; nobody works the step twice. State `building`: the engine, the HTTP surface, the web app and
the chat name their tests; the MCP surface (#406) and the automated takeover test remain.
