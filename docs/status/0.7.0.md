# Status of `0.7.0` — second domain

Part of `docs/status.md`: how far `0.7.0` has got, checked against the code and the tests.
What the milestone must reach is in `docs/roadmap.md`. Kept current by every pull request that
changes its state.

**BPMN in as a plan draft, out as an export** (#345, UC-4.23 `verified`, ADR-0168). A BPMN 2.0 model is read, defused — no document type, no entity, nothing it refers to — into one plan draft per process: every task a proposed step with its dependencies, the role its lane suggests and the method kinds its kind of task suggests, no method chosen, and every question named; a performer is never imported and a loop is dropped with a note. A draft is never a version: `complete` turns the filled draft into a bundle that passes registration's checks, or names every open question. A version exports as BPMN with its gateways, a lane per role, Taktus's extension and a diagram, and every bundle of the repository round-trips its graph, roles and gateways. `taktusctl bpmn draft`, `complete` and `export`, without an instance. The web app's plan dialogue does not read a draft yet.

**Package C builds `0.7.0` whole** (DEC-0222), on the branch `concept/package-c`.

**Taktus on more than one node** (#342, ADR-0165). Artifact bytes go to the directory, as
before, or with `TAKTUS_OBJECT_STORE=s3` to a bucket of an S3-compatible store, signed by
signature version 4 on the HTTP client the control plane already has: no library is added.
Both adapters pass one suite (`tests/adapters/objectstore/`), the S3-compatible one against an
independent server of the interface. The chart's profile `ha` renders at least two replicas,
a disruption budget and anti-affinity per role and no volume shared by roles; it refuses the
filesystem store and the chart's own single database. `helm template` of it is checked by
`tests/governance/test_chart.py`. Not yet run on a cluster of several nodes; the external
security review of `1.0.0` is to cover the profile.
