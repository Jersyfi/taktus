# Status of `0.7.0` — second domain

Part of `docs/status.md`: how far `0.7.0` has got, checked against the code and the tests.
What the milestone must reach is in `docs/roadmap.md`. Kept current by every pull request that
changes its state.

**Autonomy per action class in production use** (UC-7.1, ADR-0170). A tenant's risk class may
carry a level: a ceiling for every step of every process that uses one of its actions, taken on
when a run is created, so that a blueprint's bundle stays the same for every tenant. B-10.03 is
the first process in production use with a level per action: its booking at level 2 inside a
level-3 process, counted per action class (ADR-0110). Migration 0095.

**Connectors for documents and accounting** (UC-15.8 `verified`, ADR-0169). The documents
connector reads an inbox folder over WebDAV and each invoice in it as the business terms of
EN 16931, from UBL 2.1 or CII D16B, a declared entity refused unparsed. The accounting connector
reads orders, proposes bookings and submits released payments through a generic interface, both
writes `marked`. Both pass the conformance suite against fakes. Neither has run against a real
inbox or accounting system: that needs the tenant's credentials, `DOCUMENTS_TOKEN` and
`ACCOUNTING_TOKEN`.

**Package C builds `0.7.0` whole** (DEC-0222), on the branch `concept/package-c`.

**The second domain: invoice to payment** (#402, UC-04, ADR-0169). B-10.03 runs as a bundle:
an invoice read, its order read, every amount computed again by EN 16931's calculation rules in
decimal and matched against the order by the rule `invoice`, `exact`; a booking proposed after a
person's confirmation; the payment submitted only after a person's release at the legal anchor,
with the rule's amount. Proven end to end against fakes. Not built: the daily collection of the
inbox, the classification of an invoice that names no order, and a run against the tenant's real
systems. **Not to be used before the legal-anchor catalogue is reviewed for the tenant's
jurisdiction by a tax adviser** (DEC-0029).
