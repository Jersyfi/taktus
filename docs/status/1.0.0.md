# Status of `1.0.0` — contracts, licence, opening

Part of `docs/status.md`: how far `1.0.0` has got, checked against the code and the tests.
What the milestone must reach is in `docs/roadmap.md`. Kept current by every pull request that
changes its state.

**Data-protection requests and the processing evidence** (#657, UC-11.2 `built`, ADR-0176).
`taktusctl subject prepare` names a kind — access, rectification, erasure, portability — and a
subject, and lists every run that served one of the subject's cases, found through the
provenance records whose scope names it and through the runs' intake, with each step, object
and trace line. Preparing changes nothing. `taktusctl subject confirm --identity-checked`
carries it out for the person who checked the requester's identity, on exactly the holdings
they were shown: an erasure removes a run's inputs, stored results, artifacts and trace,
keeps an object another run of the instance still references, and verifies the ledger from its
first entry and each run's provenance chain after it; an export is generated and never stored;
a rectification is recorded as done by the person at the source. The ledger names the request,
never the subject. `taktusctl evidence` prints what is processed, where, by which adapter and
kept how long, generated from the register of what acts, the tenant's declarations and the
ledger, marked as not legally reviewed. Migration 0097. No REST route and no page in the web
app yet; a blueprint process that prepares a request as a step (B-3.08) is not built.
