# UC-12.1 — Rolling out assistants into communication tools

## 1. What must be achieved

From Taktus an organisation creates an assistant — a company chatbot in its team chat, for
example — and rolls it out. It is configured in dialogue, and run, watched and accounted for by
Taktus. The assistant is an ordinary Taktus process with an agent: the same governance, the same
reports, the same value balance. The channel it is rolled out into is a **rollout channel**, which
differs from a **command channel**: in a command channel a person commands Taktus with their own
rights (UC-1.7); in a rollout channel a person uses an assistant, which acts with the agent's rights
and the person's own credentials. Rolling out into a new channel needs no code.

## 2. How it is verified

- An assistant is a registered process version with an agent (UC-8.7). Its runs are in the ledger,
  the reports and the value balance like those of any process; no assistant runs outside a process.
- In a rollout channel every request is served with the user's own credential, within what the
  agent may do. A user without a credential for a source gets nothing from that source; what the
  agent may not do, no user's credential makes possible.
- A message in a rollout channel never becomes a command to Taktus. It cannot start, change or stop
  any process other than the assistant's own.
- Every channel is configured as a command channel or a rollout channel, and a test sends the same
  message through one of each and finds a command in the first and an assistant's answer in the
  second.
- Rolling out into a further channel of a kind Taktus has a connector for is configuration only.
- An assistant can be switched off and exported like any process; nothing about it is compulsory.

## 3. Where the boundary lies

**Not a chat tool.** The assistant lives in the organisation's own communication tool (principle 1).
**Not the IT service chat.** The reference assistant, UC-12.2, is a deployment and is described in
`blueprints/it-operations/`. **Not composing any case**, which is UC-12.3.
