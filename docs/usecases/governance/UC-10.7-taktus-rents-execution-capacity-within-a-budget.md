# UC-10.7 — Taktus rents execution capacity within a budget

## 1. What must be achieved

Where the user allows it, Taktus adds and returns machines for its execution units at a provider
the user configured. An execution unit is what carries out a step: a coding agent, a training
run, a browser. Taktus does this only within a budget and a frame the user sets: which sizes,
and how many machines at most. It never rents, changes or returns the ground it runs on itself:
the machines of the control plane and its database stay the operator's (ADR-0025).

Taktus decides from evidence whether work is better served by a base, rented continuously, or by
burst capacity, rented by the hour while work waits and returned afterwards. The evidence is the
measured waiting time and utilisation of the recent weeks. Renting burst capacity within the
budget Taktus does on its own. Raising the base it proposes to a person.

Machines, utilisation, waiting time and cost are shown over time, in reports and in graphs.

## 2. How it is verified

- No machine is rented where the user has not allowed it, at a provider the user did not
  configure, outside the frame's sizes, or beyond its count. A request that would cross any of
  these is refused before the provider is called, and the refusal names the limit.
- Every machine rented or returned is a step with a reason, admitted against the budget before
  it starts (ADR-0005), and a ledger entry naming the machine, the reason and the estimated
  cost. A rental that does not fit what remains of the budget is not made.
- The choice between base and burst is made by a reproducible method — a rule or a statistic —
  over recorded waiting times and utilisation. Given the same records it gives the same choice.
  A language model never makes it.
- Raising the base is a decision request to a person; it is never carried out without that
  person's answer (a limit, M3.10).
- The cost of each machine is read from the provider's bill and compared with its estimate. A
  difference is recorded and shown.
- No configuration of this capability can rent, change or return a machine of the control
  plane or its database. A credential that administers the installation's own platform is
  refused (DEC-0133).
- The provider is reached through an adapter by capability; removing it leaves every process
  running on the capacity that remains (the removal test).

## 3. Where the boundary lies

- Taktus does not administer the machines it runs on, nor any machine outside the frame.
- It does not choose a provider: the user configures one, or none.
- It does not negotiate prices or contracts with a provider.
- Placing the control plane itself across machines is the operator's (UC-10.1).
