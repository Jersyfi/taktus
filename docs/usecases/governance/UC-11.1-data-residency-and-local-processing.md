# UC-11.1 — Data residency and local processing

## 1. What must be achieved

An organisation decides where its data is processed — only on its own infrastructure, only in the
European Union, or anywhere — for the whole organisation, for a process, and for a class of data.
Data of a sensitive class can be kept, by rule, to models and workers that run locally. Taktus holds
to the rule on every path, and can show that it did.

## 2. How it is verified

- A residency rule is set per tenant and can be narrowed per process and per data class; where
  several apply, the narrowest holds. A rule can be narrowed below the tenant's, never widened
  beyond it.
- Every model, worker and connector an instance is configured with has a declared location. A
  process version that would bind a step handling a restricted data class to an adapter outside the
  permitted location does not register; the finding names the step, the data class and the adapter.
- At run time, a step that would send restricted data outside the permitted location fails at its
  boundary without sending anything, and the failure names the rule.
- Every outward effect is recorded with the location it went to (ADR-0022). For each rule a test
  sends data of the restricted class through a process and finds no egress entry outside the
  permitted location.
- The hosts an execution unit may reach are only hosts in the permitted location for the data it
  handles.

## 3. Where the boundary lies

**Not certifying a provider.** The location of an adapter is declared by whoever configures it;
Taktus holds processes to the declaration and does not verify a provider's own claims. **Not
classifying data.** A data class is declared on the process and its inputs; Taktus does not infer
it. **Not the data-protection tools** — access, erasure, portability (definition `UC-11.2`). **Not
air-gapped operation**, which is an installation of Taktus, not a rule inside it (definition
`UC-10.1`).

## 4. What it rests on

Egress entries for every outward effect (ADR-0022); where an instance may run (ADR-0025); the
frame's allowed hosts for execution units; model routing (`0.4.0`), which the rule steers, hence the
version. Definition `UC-11.1`.
