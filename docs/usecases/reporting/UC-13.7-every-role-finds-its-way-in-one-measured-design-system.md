# UC-13.7 — Every role finds its way in one measured design system

## 1. What must be achieved

Each person who reads Taktus — a decider, a person whose step waits, an operator, a process
owner, management, an administrator — finds in the web app what waits for them first, and
reaches every page from wherever they are, on any width. What the surface does not let them read
is said, not hidden behind a page that fails.

The web app is drawn from one design system that the owner's applications share. Every colour it
shows is readable: its contrast is measured in a light and a dark mode, never assumed.

## 2. How it is verified

- **One list of destinations.** Every page of the web app belongs to exactly one destination of
  one list, and every destination leads to a page that exists. A test reads the pages from the
  routes and fails a page no destination reaches.
- **What waits comes first.** The start page shows what waits for the reader before what runs,
  and a destination whose page holds something waiting for the reader carries a mark. A mark is
  set only from the surface's own lines; a kind the surface refused the reader sets none.
- **One design system.** Every colour, type size, spacing and movement of the frame is a token
  of the design system. A colour written as a literal in a page's style fails a test, and so
  does a custom property no token declares.
- **Contrast measured.** In both modes, text is at least 4.5:1 against every plane it is set on,
  and every mark that tells a method's family apart, every chart series and the focus ring is at
  least 3:1 against the planes it is drawn on (WCAG 2.2, SC 1.4.3 and 1.4.11). A test measures
  every pair.
- **Colour never alone.** A family of methods and a state are told apart by form, as UC-6.10
  requires. The hue only repeats the form.
- **Calm on request.** Under the system's reduced motion, or the reader's *Stop motion*, the frame
  moves nothing.
- **No figure about a person.** No mark, order or figure the frame draws names a person or compares
  people (principle 14).

## 3. Where the boundary lies

**Not a permission set.** The order of the destinations follows what each role tries to do; it
grants nothing and hides nothing, as `docs/vision/personas.md` says of a persona. **Not
personalisation.** A reader does not reorder the destinations. **Not the components of another
product.** Only the design system's foundations are shared. **Not a search.** Finding a run or a
process by its name is not required here. **Not the views of UC-6.4**, which decide what a role
sees in a report.

## 4. What it rests on

UC-6.10, the live representations and their distinctions; ADR-0059, the visual vocabulary;
ADR-0177, the design system in tokens; ADR-0178, the one navigation list and the start page;
`docs/vision/personas.md`. The owner asked for the redesign in DEC-0227 item 3. Written as a
`restoration` notice, NTC-0260, with the number package E gave it.

## 5. What is proven so far

`test_web_design_system.py` measures every text and every family's mark in both modes, holds
Taktus's layer to the primitives, refuses a colour literal, a literal type size and a literal
radius in a page (NTC-0289), and reaches every page from one destination. In the web app,
`design.test.ts` measures every text and mark against its planes in both modes, takes every value
of Taktus's layer from a primitive, and fails a colour literal, a literal type size or radius, or
an undeclared custom property in any page. The tokens are copied from the design system at
Hubtask's commit `617bd76c5`.

The navigation has five bands with a fold each, at most fifteen first entries, tabs for the pages
that answer one question, a trail of links to where the reader stands, and a bottom bar on a
phone (ADR-0321). `navigation.test.ts` reaches every route from one destination, leads every
destination, tab and bottom-bar item to a page, and sets a mark only where a line waits; the
frame reads the marks again when a decision request changes.

What waits comes first: Today's pulse card opens with how many items wait for the reader, and the
list of waits follows the glance strip, before what runs (NTC-0290, ADR-0322 §4). Under the
system's reduced motion or the reader's choice, no transition and no animation runs.

Not proven: spacing is still written in `rem` in many pages and is not held to the tokens by a
test (NTC-0289 §3). The entry *Ask Taktus* leads to `#/ask`, whose page the conversation area of
the same concept branch builds; `navigation.test.ts` excepts that one route by name until it is
there.
