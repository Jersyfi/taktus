# Beyond 1.0.0

Ideas that follow from the vision and need a decision after 1.0.0. None is pulled forward, and
each needs its own decision when its time comes.

---

**An open process bundle format as a standard.** A process — definition, prompts, skills,
connector capabilities as capabilities rather than products, governance rules, value criteria —
as one portable, versioned package, comparable to a container image for processes. A bundle is
already a set of plain files a person writes and registers (ADR-0011); exporting a registered
version back out does not exist yet. The step beyond is specifying the format openly so that
other orchestrators can read it. That makes principle 13 meaningful beyond Taktus.

**Federation between instances.** Family to business, business to supplier, authority to
authority — processes crossing instance boundaries with governance on both sides, mutual
channel identity, and no central instance. European in shape: sovereign nodes rather than a
platform. Requires the bundle format.

**A process marketplace with governance.** Verified bundles, agents and skills from third
parties, with integration-code review and a maturity level, for organisations without their own
automation competence. The internal catalogue is the precursor.

**Anonymous value benchmarks, opt-in.** Comparing the value ledger of a process against similar
processes in other instances. Process level only, never personal, only on active participation.

**Process replay for audit and training.** Every execution is step-atomic and fully recorded, so
a run can be replayed step by step — for audits, for fault analysis, and as teaching material.
The rehearsal mode built for the removal test is the first half of this capability.

**Founding from blueprints.** A founder describes a business model; Taktus proposes the domains,
suitable systems, the legal anchors for the jurisdiction and a starting value ledger — a company
laid out as a virtual agent business from day one, with a person as owner and decider. Requires
several matured blueprints and the marketplace.

**The worker contract as an open specification.** If it proves itself, publish it so that
execution units implement it natively and operators choose from a growing field instead of
maintaining adapters.

**Taktus managing its own infrastructure.** Where the environment permits it and a budget is
set, scaling resources is a step like any other — with admission control and a ledger entry.
This is where the operations blueprint stops being a second use case and becomes the same
capability.
