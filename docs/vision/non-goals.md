# Non-goals

What Taktus deliberately is not. A non-goal is as binding as a principle: crossing one is a
decision for the owner, never a convenience.

---

**Not a tool landscape.** Taktus replaces no ticket system, repository or knowledge tool and
builds no parallel world. It orchestrates what is there.

**Not a visual block builder as the primary interface.** Visualisation serves transparency, not
manual construction.

**No decisions outside the defined frame.** Strategic and conceptual direction stays with
people. Where an act is legally bound, it stays with a person regardless of the autonomy level.

**Not an ERP, an accounting system or a CRM.** Domain blueprints conduct the systems that exist.
Taktus keeps no books, no customer master data and no contracts as a system of record.

**Not a surveillance tool.** Taktus data steers processes and cost, never people.

**No lock-in, including into Taktus itself.** Every definition, prompt, skill and datum is
exportable.

**No coding agent and no agent runtime as a core product.** That layer is commodity and is
integrated through the worker contract. The value is in the control plane.

**No foreign gateway or runtime product as the core.** Channel normalisation, governance and
the ledger stay first-party. Libraries may be used inside an adapter.

**Nothing Taktus produces is compulsory.** Assistants, dashboards, documentation and skills are
Taktus processes or artifacts in open formats — exportable, removable, switchable off.

---

## One non-goal that was wrong and has been corrected

The original definition said: *no model training as a core product*.

That is now split, because method selection made the distinction load-bearing:

- **Foundation models: still a non-goal.** Taktus does not train them and does no model
  research.
- **Task-specific models for process steps: a core function.** When a step has run on a language
  model long enough to have produced consistent labelled data, training a small model for it —
  cheaper, reproducible, one exactness class higher — is exactly what Taktus is for.

That is the difference between a model vendor and an orchestrator that picks the right tool.
