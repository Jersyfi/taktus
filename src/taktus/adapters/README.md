# Adapters

Driving adapters call into the core; driven adapters are called by it through ports
(`docs/architecture/project-structure.md` §3).

| Adapter | Kind | Status |
|---|---|---|
| `driving/cli` | `taktusctl`: `conformance run` drives the conformance suite; `guides check` and `guides publish` render the guides from the repository and put them into a directory (ADR-0065); `run` executes a bundle in this process and `submit` queues it for the daemon, both through the services the composition root hands it (`cli/wiring.py`) | exists |
| `driving/rest` | the HTTP surface of `taktusd`: `/health` and `/ready` on every process, and with the `api` role `/intake/{channel}` (webhook intake through the connector port), `/runs`, `/runs/{id}`, `/runs/{id}/ledger` for a reader whose account key proves an identity, `/findings/intake` for another instance's signed findings where the operator opened it (ADR-0118); everything under `TAKTUS_PATH_PREFIX`, every error an RFC 9457 problem; `api/openapi.yaml` is generated from it | exists; no write beyond intake, no UI |
| `driven/workers/http` | the worker port over HTTP and SSE, the client side of `contracts/worker/v1`; `workers/pool.py` maps required capabilities to a configured worker | exists |
| `driven/memory` | repositories, ledger store, object store, queue and leadership in memory with an optional file snapshot — **development and test only**; answers the same suites as the database | exists |
| `driven/postgres` | the persistence port over PostgreSQL: SQLAlchemy Core, one mapper per aggregate's document, the application role and the tenant set per transaction, `lock_timeout` and `idle_in_transaction_session_timeout` on every connection (`TAKTUS_DATABASE_LOCK_TIMEOUT_SECONDS`, `TAKTUS_DATABASE_IDLE_IN_TRANSACTION_SECONDS`), the ledger store with its chain claim — the only lock on a tenant's chain, in one process as across instances; the queue port over `claim_jobs` (`SELECT … FOR UPDATE SKIP LOCKED` with a lease), and its fence, a `FOR SHARE` read of the claim inside every write under it; the leadership port over a session-level advisory lock; `migrate.py` runs the migrations and checks the revision | exists |
| `driven/configuration` | the configuration port over `TAKTUS_*` environment variables; a secret is read from the file `TAKTUS_<KEY>_FILE` names, and both at once is refused | exists |
| `driven/connectors/mcp` | the connector port as an MCP client: the `intake` tool of whichever connector serves a channel (`TAKTUS_CONNECTORS`); the operations follow with the run's binding | exists, intake only |
| `driven/clock` | system time, identifiers, randomness: the one place the control plane reads them | exists |
| `driven/signing` | the reporting component's `Signatures` over Ed25519: the key a sender signs its findings with, derived from a seed the component keeps, and the check the intake makes (ADR-0118) | exists |
| `driven/telemetry` | no-op spans; an OpenTelemetry exporter later | exists |
| `driven/connectors/github` | the reference connector behind `contracts/connector/v1`: an MCP server against a repository hosting service — issues, pull requests, pipelines, comments as actions with a declared effect and a marked idempotency key; webhook intake verified and normalised into commands; fault injection for the suite. Named by capability everywhere but in its own directory | exists; reached by the daemon's webhook intake; its operations are not yet called from a process (the run's binding is `0.2.0`) |
| `driven/connectors/bookstack` | `knowledge.pages` against a wiki of shelves, books and pages over MCP, the mark, the key and the digests kept in the page's tags: the wiki the guides are read in (UC-13.6, NEED-0021). Named by capability everywhere but in its own directory | exists; passes the connector suite against a fake of the wiki; not yet deployed on an instance |
| `driven/connectors/directory` | `knowledge.pages` over a directory of Markdown files, one per page, the mark kept in a comment on the file's last line: the knowledge system of an organisation that has none (ADR-0065) | exists; in process, used by `taktusctl guides publish` |
| `driven/connectors/mail` | `mail.messages` and `channel.mail` over IMAP and SMTP: a read, a send `marked` by its message identifier, a reply; a relay delivers the inbox to the intake, signed, one event per message identifier (ADR-0111) | exists; passes the connector suite against a fake mail server; no process uses it yet |
| `driven/connectors/prometheus` | `metrics.series` over the Prometheus HTTP query API: a query at a moment or over a range, both `read` (ADR-0111) | exists; passes the connector suite against a fake store; no process uses it yet |
| `driven/connectors/httpcheck` | `check.http`: one HTTP request judged against a declared expectation, reported with its outcome and duration (ADR-0111) | exists; passes the connector suite against a fake service; no process uses it yet |
| `driven/connectors/aws` | `billing.costs` over the AWS Cost Explorer API: a cloud account's cost per day by service, account or region, each amount as decimal text and each day's total its exact sum, every request signed with the requesting identity's key pair (ADR-0150) | exists; passes the connector suite against a fake that recomputes every signature |
| `driven/connectors/openai` | `models.costs` over a model provider's organisation costs API: the cost per day by line item or project, in the shape `billing.costs` has (ADR-0150) | exists; passes the connector suite against a fake of the API; no process uses it yet |
| `driven/connectors/anthropic` | `models.costs` over a model provider's Admin API cost report: the cost per day by description or workspace, cents turned into dollars exactly, in the shape `billing.costs` has (ADR-0150) | exists; passes the connector suite against a fake of the report; read by the model cost watcher, B-2.01 |
| `driven/connectors/sentry` | `errors.issues` over an error tracker's API: the issues of a period, and one issue, with their counts; never a person's field (ADR-0150) | exists; passes the connector suite against a fake of the API; no process uses it yet |
| `driven/connectors/stripe` | `payments.subscriptions` over a payment provider's API: the subscriptions of a status, and one subscription, with their items; never a customer's name, address or payment method (ADR-0150) | exists; passes the connector suite against a fake of the API; no process uses it yet |
| `driven/connectors/vendor` | a vendor's own MCP server behind the contract: its tools served as the operations a manifest declares, with their effect and idempotency; without a manifest only the tools the vendor marks as reading, each a read (ADR-0117) | exists; passes the connector suite against the MCP project's reference time server and a stand-in with tools that write; no process uses it yet |
| `driven/connectors/serving.py` | the MCP server, the credential read from its file and the faults the nine connectors above share | exists |
| everything else | see the tree in the project structure | from later versions |
