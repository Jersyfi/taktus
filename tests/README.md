# Tests

One directory per gate (docs/architecture/project-structure.md §2). A directory with no tests yet
reports "no targets yet" and green: `tools/gate.py` turns pytest's "no tests collected" into
success and nothing else.

PostgreSQL comes from testcontainers, once per session, migrated to the current schema
(`conftest.py`). Without Docker the tests that need it skip and name the reason; with
`TAKTUS_REQUIRE_DATABASE` set — CI — they fail instead. `TAKTUS_TEST_DATABASE_URL` points them
at an existing, empty database. Tests keep apart through tenants and never clean up. The
container execution tests and the image tests need Docker the same way (`engine_socket`,
`reference_worker_image` in `conftest.py`): they skip without it and fail under
`TAKTUS_REQUIRE_DATABASE`, which in CI means "Docker is required here".

| Directory | Gate | Checks |
|---|---|---|
| `architecture/` | `make gate-arch` | adapter obligation, component boundaries, no product name in the core (ADR-0003, ADR-0016) |
| `conformance/` | `make gate-conformance` | both contracts. Worker: the stream rules against every transcript fixture; the suite (`src/taktus/conformance`) against the reference worker in both profiles, started as a separate process; the meta-test: every fault the reference worker can inject fails exactly its check; the same suite and the same meta-test against the coding worker in both authentication modes, run against its fake agent, plus a session that expires mid-run halting at the boundary and resuming, an exhausted window blocking, and an assignment without the credential rejected before the agent starts. Connector: the rules against known-good and known-bad documents; the suite over MCP against the reference connector, started as a separate process against the fake service (also a process); the meta-test per fault; and what the fake holds afterwards — every write acted exactly once per key. `taktusctl conformance run` end to end for both |
| `governance/` | `make gate-governance` | anchors hold, limits never breach, least privilege; today: the correction anchor's trigger — a result has left the system exactly when an egress entry names it or anything derived from it (ADR-0022) — and the execution rule of ADR-0002 as a table: no isolation is refused from autonomy level 3 and when the level is unknown, and the process adapter refuses before it starts anything |
| `exactness/` | `make gate-exactness` | an `exact` step never takes its final value from a variable method (ADR-0014, ADR-0018): on the shared kernel's `Step`, on the process domain's own rule, on every example bundle and every blueprint bundle, and at run time — an exact step executes as a rule of the run component |
| everything else | `make test` | `composition/`: the daemon's settings — every `TAKTUS_*` variable validated with a message naming it, the effective configuration with every secret masked, and that no secret value reaches a log line rendered through the daemon's own processor chain · `contract/`: the Python bindings of the shared kernel, the worker contract and the connector contract match the schemas, their enumerations and patterns, and every example · `components/<name>/`: domain rules as tables, no mocks; `components/process/test_bundle_parsing.py`: a bundle whose `autonomy` is a bare level, lacks its reason or its `toward_next` below 4, or carries one at 4, does not register (ADR-0026); `components/catalog/test_removal.py`: the removal verdicts — a step changes with an alternative adapter or a fallback to a person and breaks otherwise, two runs compared by where they came to, the database as the known exception, *verified* needing both halves; application services against `fakes/` (a deterministic clock and identifiers, a scripted worker); `components/run/test_provenance.py`: a record for every completed step, the chain behind an artifact, no gap across a stop or a crash, growth within the bound of ADR-0021, what `verify` finds · `components/run/test_connector_steps.py`: connector steps against a fake connector with a memory — a read's source in the provenance, a write's egress entry the correction anchor finds, a crash after the target acted replayed on recovery with the same key, a retryable failure keeping the attempt and a non-retryable one starting a new attempt, an operation with `idempotency: none` never repeated by the run, checks, templates, artifact and input references, a wait on an external state and its timeout · `components/run/test_llm_steps.py`: llm steps against a fake model — the prompt rendered from references, the answer checked before it leaves, tokens counted, the answering model in the provenance · `components/command/test_complete_intake.py`: an intake event placed by the identity port and completed into a command that says its identity is provisional · `adapters/`: what is particular to one adapter; `adapters/connectors/`: the reference connector against `fakes/repository_service.py` in a thread — the restart test (a pull request opened for a step, then the same step on a connector with no memory of it: one pull request; the same for a branch), permissions passing through, every error cause, labels as their own mark, the pipeline's verdict for a branch, intake from the recorded payloads with the signature verified before the body is read; the action half of the port over MCP against the reference connector in process; and `test_repository_live.py`, the restart test against the real service — a branch, a pull request, a comment and a label, each twice across two connectors — which runs when `TAKTUS_LIVE_REPOSITORY` and `REPOSITORY_TOKEN` are set and skips otherwise; `adapters/models/`: the model adapter against `fakes/model_service.py` — messages out, a completion with its usage in, the credential in the header and in no error; `adapters/test_provisional_identity.py`: one configured operator per tenant, nobody placed without a tenant when there are several; `adapters/telemetry/`: spans nested run → step → worker call, the connector call as a span, every ledger entry carrying its trace id, a log line inside a span carrying it, no person and no secret in any attribute, nothing exported without an endpoint;
