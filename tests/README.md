# Tests

One directory per gate (docs/architecture/project-structure.md §2). A directory with no tests yet
reports "no targets yet" and green: `tools/gate.py` turns pytest's "no tests collected" into
success and nothing else.

**Tests stay true over time, not once.** A hole in a gate's coverage found on the way is a
finding — recorded, not noted — and a gate that has become too slow to be useful is a finding
too, reported with its cost before and after: every gate prints its duration as its last line
for that. A gate is weakened only under a notice that demonstrates it had no value
(anchors.taktus.md M2.3); "it was slow" is a cost to report, not a reason to remove.

PostgreSQL comes from testcontainers, once per session, migrated to the current schema
(`conftest.py`). Without Docker the tests that need it skip and name the reason; with
`TAKTUS_REQUIRE_DATABASE` set — CI — they fail instead. `TAKTUS_TEST_DATABASE_URL` points them
at an existing, empty database. Tests keep apart through tenants and never clean up. The
container execution tests and the image tests need Docker the same way (`engine_socket`,
`reference_worker_image` in `conftest.py`): they skip without it and fail under
`TAKTUS_REQUIRE_DATABASE`, which in CI means "Docker is required here".

The images those tests run are built through `tests/images.py` and nowhere else: labelled with a
digest of their Dockerfile and every file it copies, tagged with that digest, and not handed to
`docker build` at all when the content tag carries that label. A needed build writes plain
progress to `.pytest_cache/taktus-images/<tag>.log`; one silent for 120 s or past its bound is
stopped, and the first test that needs it fails naming the image, the unfinished step, the last
lines and the log — locally as in CI, since a hung build is a finding, not a skip; every later
test that needs it fails in one line. `make images` builds them ahead (DEC-0036, NTC-0007).

The web app has its tests beside its code, under `web/src/` as `*.test.ts`, run by `make
gate-web` with the web app's own runner (ADR-0063). Without Node that gate skips and says so;
with `TAKTUS_REQUIRE_NODE` set — CI — it fails instead. They render the web app's drawing and
read back every token it drew, against a run level `reporting` drew (`make generate` writes it
to `web/src/lib/generated/fixtures.json`; `components/reporting/test_run_level.py` fails a stale
copy): a token other than the one handed over fails, and so does a vocabulary token with no
drawing. They also hold the stream's reading — the key in the header only, the resume from the
last position — and that a change on the stream reads the level again without a reload.
